The instruments

Note plays a single note. Phrase plays a few notes rising, so you hear it sing. x4 fires the note four times fast, to hear it as a repeated navigation cue.

Spin soundscape

A plucked arpeggio built from one instrument, pitch-shifted across a pentatonic scale. Speed sets the note rate (zero is silent); height shifts the register. Pick an instrument, then Start.
