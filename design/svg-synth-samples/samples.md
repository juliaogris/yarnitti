# Slopes samples — reference art from tinkersynth

Generative line art exported from the tinkersynth "Slopes" machine
(`https://www.tinkersynth.com/`), kept as visual reference for the yarnitti
wave header. tinkersynth exports bare SVG paths only, with no embedded
parameters or seed, so these are geometry references, not reproducible state.

| File                          | tinkersynth art-name | What it is                                            |
| ----------------------------- | -------------------- | ----------------------------------------------------- |
| `arch-skein-dark.svg`         | "superb design"      | The target look: a polar arch / yarn skein, white on black, feet trailing down. |
| `arch-skein-feet-annotated.png` | (screenshot)       | The arch with both feet circled, marking where strands fade to a vertical line. |
| `slopes-panel-values.png`     | (screenshot)         | The Slopes control panel for the arch. Seed `036170`, line count `34`, polar slider high, peaks mid. |
| `slopes-dense-dark.svg`       | "sublime treasure"   | Very dense field (14k paths), white on black.         |
| `slopes-horizontal-light.svg` | "resplendent canvas" | Sparse horizontal slopes (62 paths), black on white.  |

The header prototype lives in the repo root at `6-wave-header/`.
